# ملاحظات إصدار Optimum 5.5.2

- Access Engine موحد يجمع الباقة والدور والإضافات والاستثناءات والنطاق.
- Entitlements قابلة للتحكم من Platform Console.
- Role Draft / Publish / Impact / Version / Rollback.
- View as User وRole Comparison.
- هيكل تنظيمي وRole Add-ons وAccess 360.
- دورة حياة موظف وخطة Offboarding وتسليم المهام والعهدة.
- Workspace Settings Draft / Publish / Rollback.
- تطبيق نطاق الموارد على RLS وعمليات التعديل.
- 33 فهرسًا مضافًا لعلاقات Phase 5.5 وإزالة سياسات قراءة مكررة.
- إصلاح عقد RPC لحفظ ملف وصول العضو وإعدادات الحوكمة.
- Edge Function `identity-provisioning-v55` منشورة ومحمية بـJWT.

هذه نسخة مراجعة وتطوير، وليست إعلان نشر عام. ما زال Production Build والبريد وMFA وLeaked Password Protection ضمن بوابات ما قبل النشر.
