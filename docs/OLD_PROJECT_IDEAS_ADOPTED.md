# الأفكار المستفاد منها من المشروع القديم

تمت دراسة وحدة الرسم في المشروع المرسل، ولم يتم نسخ المشروع أو إعادة إدخال تعقيده. تم أخذ الأنماط المفيدة فقط وإعادة بنائها داخل معمارية Optimum الحالية:

1. **السحب باستخدام فرق إحداثيات المؤشر** بدل إعادة بناء اللوحة أثناء Pointer Down.
2. **حساب نقطة الكانفس من Bounding Rectangle** لمنع انعكاس أو قفز الإحداثيات في RTL ومع Zoom.
3. **Connect Mode** باختيار بداية ونهاية ثم إدخال نوع الربط.
4. **Route Sketch** متعدد النقاط مع طول فعلي.
5. **Validation Issues** مرتبطة بالعنصر ويمكن الانتقال إليها.
6. **فصل بيانات العنصر عن الرسم البصري** حتى تظل البيانات قابلة للحفظ والحصر والتصدير.

لم يتم نقل أي أجزاء قديمة تخص قواعد بيانات أو واجهات أو Workflows لا تناسب النظام الجديد.
