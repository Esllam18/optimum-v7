# QA Checklist — Optimum Phase 4.11

## قبل التشغيل

- [ ] فك النسخة في فولدر جديد.
- [ ] اقفل أي Portable Server قديم يعمل على المنفذ 4173.
- [ ] شغّل `start-portable.bat`.
- [ ] افتح `http://localhost:4173` واضغط `Ctrl + F5`.

## الهيدر والتنقل

- [ ] لا توجد روابط مكررة تفتح نفس الصفحة.
- [ ] الرسم يفتح Workspace الحالي.
- [ ] إدارة تفتح إدارة الرسم.
- [ ] المراجعات تفتح سجل المراجعات.
- [ ] الحصر يفتح الحصر والتقارير.
- [ ] الملفات تفتح Files Workspace.
- [ ] أدوات الرسم والتعديل والرؤية موزعة في مجموعات واضحة.
- [ ] زر العناصر يعيد فتح مكتبة العناصر بعد إغلاقها.
- [ ] زر الخصائص يعيد فتح لوحة الخصائص.
- [ ] زر المسارات يعيد فتح Dock المسارات.
- [ ] زر الخريطة يعيد فتح Mini Map.

## الحفظ

- [ ] `Ctrl + Shift + S` يحفظ الرسم داخل قاعدة البيانات.
- [ ] `Ctrl + S` يحفظ ثم يفتح Dialog الحفظ داخل Files Workspace.
- [ ] زر «حفظ في الملفات» لا يفتح File Picker الخاص بويندوز.
- [ ] يمكن اختيار فولدر داخل المشروع/الموقع.
- [ ] يتم إنشاء مستند وربطه بالمراجعة الحالية.
- [ ] زر تصدير فقط هو الذي ينزل ملفًا على الجهاز.

## مكتبة العناصر

- [ ] زر X يخفي المكتبة فقط ولا يخرج من الرسم.
- [ ] يمكن إعادة المكتبة من الهيدر.
- [ ] يمكن تغيير عرض المكتبة بالسحب.
- [ ] العائلات لها أسماء واضحة.
- [ ] لا توجد مجموعات متعددة باسم «عناصر أخرى».
- [ ] العنصر غير المصنف يظهر باسم رمزه أو كوده الفعلي.
- [ ] المفضلة والتجميعات ما زالت متاحة.

## لوحة الخصائص

- [ ] يمكن تغيير عرضها بالسحب.
- [ ] إخفاؤها لا يخرج من الرسم.
- [ ] إعادة فتحها لا تغير الرسم أو التحديد.

## مكتبة المسارات

- [ ] زر X يخفي Dock المسارات فقط.
- [ ] يمكن إعادة فتحه من الهيدر.
- [ ] يمكن تغيير ارتفاعه بالسحب من الحافة العليا.
- [ ] كل Route Variant في Catalog ظاهر.
- [ ] الكروت موزعة على صفين ويمكن تمريرها.
- [ ] كل كارت يعرض الاسم والعائلة وعدد الاستخدام والطول.

## نصوص المسارات

- [ ] لا توجد صناديق أو Cards خلف بيانات المسار.
- [ ] النص الفني واضح فوق الخط.
- [ ] النص لا يختفي في SVG أو PDF.
- [ ] لا يظهر تلقائيًا «مسار مقترح» أو «ميكرو دكت» كعنوان.
- [ ] يظهر العنوان فقط عندما يكتبه المستخدم.
- [ ] يمكن تحديد النص وتحريكه وتعديله من خصائص المسار.

## التصدير والطباعة

- [ ] SVG يعرض البورد كاملًا.
- [ ] Title Block لا يغطي الرسم.
- [ ] الـLegend والبيانات داخل حدود الفريم.
- [ ] Print Preview مضبوط على A3 Landscape.
- [ ] الحصر يبدأ في صفحة منفصلة.
- [ ] PDF لا يقص الرسم أو الفريم.

## AutoCAD / DXF

- [ ] صدّر DXF جديدًا من النسخة 4.11؛ لا تختبر ملفًا قديمًا محفوظًا قبل التحديث.
- [ ] افتح الملف في AutoCAD 2022.
- [ ] عند الطلب اضغط Enter ثم نفذ `ZOOM` ثم `E`.
- [ ] تأكد من ظهور العناصر والمسارات والفريم.
- [ ] تأكد من عدم ظهور `DXF read error`.
- [ ] افحص Layers والنصوص.
- [ ] لو العربية لا تظهر، راجع Text Style والخط المثبت في AutoCAD؛ هندسة الملف نفسها ASCII-safe لتفادي تلف DXF.

## Refresh والثبات

- [ ] Refresh يبقي المستخدم داخل نفس الرسم والمراجعة.
- [ ] أحجام العناصر/الخصائص/Dock المسارات تعود كما كانت.
- [ ] العناصر المخفية يمكن استعادتها من الهيدر بعد Refresh.
