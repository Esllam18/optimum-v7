# ملاحظات نسخة المراجعة 5.2

هذه النسخة مخصصة لاستكمال التحسينات والتجربة قبل النشر العام.

## الجديد

- شعار خاص لكل شركة وصورة شخصية لكل عضو، داخل تخزين خاص بصلاحيات.
- بيانات راتب وتعويضات منفصلة ومحكومة بصلاحيتي العرض والتعديل.
- Role Studio داخل كل شركة لإنشاء الأدوار وتعديلها من قوالب جاهزة أو من الصفر.
- مكتبة أدوار عالمية منفصلة داخل Platform Console يديرها Platform Admin.
- تحكم الشركة في اسم التطبيق والشعار والألوان والثيم وشكل القائمة والزوايا وكثافة الواجهة.
- تحديث دليل الفريق وإدارة الأعضاء ليعرض البيانات الوظيفية والصور وحالة الحساب بصورة أوضح.
- تحسينات بصرية Responsive للبطاقات والنوافذ وجداول الصلاحيات والهوية.
- مراجعة RLS والفهارس والسياسات بعد تشغيل Supabase Advisors.

## التشغيل

- `start-client-app.bat` لتطبيق الشركات على المنفذ 4173.
- `start-platform-console.bat` للوحة الإدارة الخاصة على المنفذ 4174.

## حالة الاختبارات

نجحت جميع اختبارات النظام من CAD 4.11 حتى Phase 5.2، ونجح اختبار تشغيل السيرفرين المحمولين. لم يتم تنفيذ Next.js production build داخل بيئة التجهيز لأن `node_modules` غير مرفقة؛ شغّل `npm install` أولًا عند الحاجة إلى بناء Next.js.
