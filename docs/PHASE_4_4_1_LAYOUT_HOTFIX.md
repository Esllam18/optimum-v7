# Optimum Phase 4.4.1 — CAD Layout Hotfix

## المشكلة

في وضع التركيز، تم نقل لوحة العناصر إلى العمود الأيمن والخصائص إلى العمود الأيسر باستخدام `grid-column` فقط. متصفح Chrome وضع كل جزء في صف تلقائي مختلف، فظهر الشيت كشريط أفقي، وظهرت الخصائص أسفله بدل بقائها بجواره.

## الإصلاح

- تثبيت مكتبة العناصر، الشيت، والخصائص في صف واحد صراحةً.
- منع إنشاء صفوف Grid ضمنية.
- جعل مساحة الرسم تملأ الارتفاع المتاح بالكامل.
- الحفاظ على Dock المسارات أسفل الرسم.
- لا توجد تعديلات على قاعدة البيانات أو بيانات الرسومات.

## التشغيل

شغّل `start-portable.bat` ثم افتح `http://localhost:4173` واضغط `Ctrl + F5`.
