# ملاحظات إصدار Optimum 5.5.2

## إصلاح أول دخول

- تغيير كلمة المرور يتم من جلسة المستخدم الحالية بدل Admin API.
- لا يتم حذف Session الحالية بعد الحفظ.
- بعد اكتمال أول دخول، التطبيق يفحص الجلسة ويحدّثها قبل تحميل مساحة العمل.
- إذا كانت الجلسة القديمة محذوفة بالفعل، يتم إرجاع المستخدم لشاشة الدخول برسالة واضحة لاستخدام كلمة المرور الجديدة.
- تمت إضافة اختبار يمنع رجوع خطأ `Session from session_id claim in JWT does not exist`.
