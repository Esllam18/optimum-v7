# Optimum Phase 4.11 — CAD Usability & Export Fix

## الهدف

هذا الإصدار يقفل مجموعة مشكلات واجهة الرسم والتصدير التي ظهرت أثناء الاختبار العملي، بدون إضافة مسارات عمل جانبية لا يحتاجها المستخدم. التركيز كان على وضوح الهيدر، إدارة مساحة العمل، المكتبات، حفظ نسخة داخل نظام الملفات، وإخراج DXF/SVG/الطباعة بشكل أكثر ثباتًا.

## 1. إعادة بناء الهيدر

تم تقسيم الهيدر إلى مستويين واضحين بدل تكرار أزرار تؤدي إلى نفس المكان:

- **الرسم:** مساحة الرسم الحالية.
- **إدارة:** بيانات الرسم والمراجعة والمرفقات.
- **المراجعات:** سجل الإصدارات والمراجعات.
- **الحصر:** جداول المواد والمسارات والعناصر.
- **الملفات:** فتح مساحة الملفات داخل النظام.

شريط الأدوات الثاني يحتوي مجموعات مستقلة:

- أدوات الرسم.
- التراجع والنسخ والحذف.
- أدوات الرؤية والتكبير.
- إظهار وإخفاء العناصر والخصائص والمسارات والخريطة.
- الحفظ في الملفات والتصدير.

تم حذف بيانات المستخدم الوهمية والروابط المكررة من وضع CAD.

## 2. الحفظ داخل مساحة الملفات

زر **حفظ في الملفات** لم يعد يفتح نافذة اختيار ملفات الجهاز. بعد حفظ الرسم في قاعدة البيانات، يفتح Dialog داخلي يتيح:

- اختيار الصيغة: DXF أو SVG أو CSV أو Excel.
- اختيار فولدر من نطاق المشروع/الموقع داخل Files Workspace.
- إنشاء مستند بإصدار أول وربطه بالرسم والمراجعة الحالية.

التصدير إلى الجهاز ما زال متاحًا من زر **تصدير** فقط، حتى يبقى الفرق واضحًا بين حفظ نسخة داخل النظام وتنزيل ملف خارجي.

الاختصارات:

- `Ctrl + S`: حفظ الرسم ثم فتح الحفظ داخل Files Workspace.
- `Ctrl + Shift + S`: حفظ فوري داخل قاعدة البيانات فقط.

## 3. المكتبات القابلة للإخفاء والاستعادة

زر X في مكتبة العناصر أو Dock المسارات يخفي الجزء فقط، ولا يخرج من الرسم. توجد أزرار ثابتة في الهيدر لإعادة فتح:

- مكتبة العناصر.
- لوحة الخصائص.
- مكتبة المسارات.
- الخريطة المصغرة.

أصبح المستخدم قادرًا على تغيير مساحة:

- مكتبة العناصر من الحافة الداخلية.
- لوحة الخصائص من الحافة الداخلية.
- Dock المسارات من حافته العليا.

المقاسات تُحفظ محليًا وتعود بعد Refresh.

## 4. تنظيم العناصر

تم إلغاء تكرار اسم «عناصر أخرى» غير المفهوم. أي عنصر معروف يدخل في عائلته الهندسية، مثل:

- الكابينات.
- نقاط التوزيع.
- بوكسات النهاية والمخارج.
- الغرف والمناهيل.
- المواقع والمنشآت.
- الأعمدة والعناصر الهوائية.
- الوصلات واللحامات.
- المعدات النشطة.
- العناصر البصرية.
- الإكسسوارات.

العناصر غير المصنفة لا تُجمع تحت اسم واحد غامض؛ تظهر تحت اسم رمزها أو كودها الحقيقي حتى يعرف المستخدم ما الذي سيضيفه.

## 5. مكتبة المسارات

تم عرض **كل Variant موجود في Catalog** بدل عرض كارت واحد فقط لكل عائلة. الـDock أصبح أعلى ويعرض صفين قابلين للتمرير، وكل كارت يوضح:

- اسم المسار الدقيق.
- العائلة.
- عدد مرات استخدامه في الرسم.
- إجمالي الطول المستخدم.

العائلات الحالية تشمل Microduct، Fiber، HDPE، PVC، Trench/Civil وSupport routes حسب البيانات الموجودة في Catalog.

## 6. بيانات المسارات كنص فقط

تم حذف صندوق بيانات المسار من الرسم. البيانات تظهر كنص واضح فوق المسار مع Halo أبيض خفيف لضمان القراءة، ولكن بدون Card أو Rectangle.

كما تم منع الأسماء العامة غير المفيدة من الظهور تلقائيًا، مثل:

- مسار مقترح.
- Suggested route.
- ميكرو دكت.
- Microduct.

لا يظهر عنوان مخصص إلا عندما يكتبه المستخدم بنفسه. البيانات الفنية مثل المقاس والكابل والكور والطول تبقى ظاهرة.

## 7. DXF لـ AutoCAD

سبب الخطأ السابق كان أن ملف DXF احتوى Sections/Entities غير مكتملة وغير متوافقة مع البنية المطلوبة، رغم أن بعض البرامج الأكثر تسامحًا كانت تقرأه.

تم استبدال المولد بنسخة محافظة ومتوافقة مع **AutoCAD R12 / AC1009** تعتمد فقط على:

- `LINE`
- `TEXT`
- Layers وLine types أساسية
- Group-code/value pairs كاملة

ولا تستخدم:

- `BLOCK_RECORD`
- `LWPOLYLINE`
- AcDb subclass markers
- Blocks غير مكتملة

يتم فحص كل ملف قبل تنزيله للتأكد أن عدد السطور زوجي وأن كل Group Code صحيح وأن الملف ينتهي بـ `EOF`.

> AutoCAD نفسه غير متوفر في بيئة التجهيز. تم التحقق بنيويًا من الملف ونجح استيراده في LibreOffice Draw وتحويله إلى PDF. يلزم اختبار نهائي على AutoCAD 2022 على جهاز المستخدم للتأكد من إعدادات النصوص والخطوط لديه.

## 8. الطباعة وSVG والفريم

تم فصل مساحة الرسم عن Title Block أثناء التكوين، ثم تجميعهما في التصدير والطباعة بمقاس A3 Landscape. التحسينات تشمل:

- احتواء الرسم بالكامل بدل قصه.
- عدم تمدد Title Block فوق البورد.
- Labels إنجليزية/عربية قصيرة لا تعبر حدود لوحة البيانات.
- الصفحة الأولى للرسم، والحصر يبدأ في صفحة جديدة.
- Route labels مرسومة بطبقتي Halo/Ink لمنع اختفاء النص في محركات SVG/PDF المختلفة.

## 9. الاختبارات المنفذة

نجحت الاختبارات التالية:

- فحص JavaScript syntax.
- Smoke tests للتطبيق.
- اختبارات حفظ Files Workspace وأزرار الهيدر.
- اختبارات إخفاء/إظهار اللوحات والمقاسات المحفوظة.
- فحص عرض كل Variants للمسارات.
- فحص عدم وجود Route Label Boxes.
- فحص DXF R12 وعدم وجود Entities المحظورة.
- فحص Group-code/value pairs ونهاية EOF.
- تشغيل Portable Server وإرجاع HTTP 200.
- استيراد DXF في LibreOffice Draw وتحويله إلى PDF.
- رندر واجهة 1648×927 بدون أخطاء Console في نموذج الاختبار.
