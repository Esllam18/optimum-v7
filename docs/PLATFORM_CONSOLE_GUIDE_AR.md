# دليل لوحة Optimum الخاصة بإدارة المنصة

## التشغيل المحلي

شغّل تطبيق الشركات أولًا:

```text
start-client-app.bat
```

ويفتح على:

```text
http://localhost:4173
```

ثم شغّل لوحة الإدارة الخاصة في نافذة مستقلة:

```text
start-platform-console.bat
```

وتفتح على:

```text
http://localhost:4174
```

اللوحة الثانية تطبيق ويب مستقل بملف تشغيل وأصول خاصة بها، ولا تظهر للمستخدمين داخل واجهة الشركة. ولا يستطيع دخولها إلا حساب موجود وفعّال في جدول `platform_admins`.

## إنشاء شركة جديدة

1. افتح **الشركات** واضغط **شركة جديدة**.
2. أدخل الهوية التجارية والقانونية ووسائل التواصل.
3. اختر الخطة وحدود المستخدمين والمشروعات والتخزين وحالة الدفع.
4. أدخل بيانات مالك الشركة.
5. راجع الملخص واضغط **إنشاء الشركة والحساب**.
6. تظهر بيانات الدخول المؤقتة مرة واحدة؛ انسخها أو افتح رسالة البريد الجاهزة.

عند دخول المالك لأول مرة، لا تُحمّل بيانات الشركة قبل أن ينشئ كلمة مرور خاصة به ويكمل شاشة تأمين الحساب.

## إضافة موظف من تطبيق الشركة

1. افتح **الفريق والصلاحيات**.
2. اضغط **إضافة عضو**.
3. أدخل بيانات الموظف الوظيفية ووسائل التواصل.
4. اختر الدور والمدير المباشر وفترة الوصول.
5. عدّل الاستثناءات الفردية للصلاحيات عند الحاجة.
6. أنشئ الحساب واحفظ كلمة المرور المؤقتة الظاهرة مرة واحدة.

لو البريد لديه حساب Optimum سابق، يُربط بالشركة الجديدة بدون تغيير كلمة مروره الحالية.

## إرسال البريد تلقائيًا

الإرسال التلقائي يحتاج إعداد Secrets التالية على Edge Function:

- `RESEND_API_KEY`
- `OPTIMUM_FROM_EMAIL`
- `OPTIMUM_CLIENT_LOGIN_URL`

قبل إعدادها، النظام يظل يعمل بالكامل ويعرض بيانات الدخول مرة واحدة مع زري النسخ وفتح رسالة بريد جاهزة.

## إضافات Phase 5.2

### شعار الشركة وهوية التطبيق

من صفحة **الشركات** افتح تفاصيل الشركة ثم اختر **الهوية والألوان**. تستطيع رفع شعار خاص، وتحديد اسم التطبيق داخل مساحة الشركة، والسطر التعريفي، واللون الأساسي ولون التمييز، والثيم الافتراضي وشكل القائمة الجانبية.

الصور لا تُعرض كرابط عام؛ تُحفظ داخل Bucket خاص باسم `identity-assets`، ويُولد لها رابط مؤقت حسب صلاحيات المستخدم.

### مكتبة الأدوار العالمية

من القائمة الجانبية افتح **مكتبة الأدوار**. بصفتك Platform Admin تستطيع:

- إنشاء قالب دور جديد بالعربية والإنجليزية.
- اختيار لون وأيقونة وتصنيف للقالب.
- تفعيل وحدة صلاحيات كاملة أو اختيار الإجراءات واحدة واحدة.
- تعليم القالب بأنه موصى به أو إيقاف ظهوره للشركات.
- تعديل القالب أو حذفه لاحقًا.

القالب لا يفرض نفسه على الشركات؛ هو نقطة بداية ذكية يستطيع صاحب الشركة نسخها ثم تخصيص الدور داخل شركته.

### الصور والرواتب

داخل تفاصيل أي شركة يظهر دليل إداري موحد يضم صورة العضو وبياناته الوظيفية والدور وحالة أول دخول. ويظهر الراتب فقط للـPlatform Admin أو للمستخدم الذي يمتلك صراحة صلاحية `compensation.view`.

بيانات الراتب مخزنة في جدول منفصل عن الملف الشخصي، وتشمل الراتب الأساسي والعملة ودورية الدفع وتاريخ السريان والبدلات والمكافأة المستهدفة.

## إدارة الأدوار داخل الشركة

صاحب الشركة أو المسؤول المصرح له يفتح **الفريق والصلاحيات → إدارة الأدوار**، ومن هناك يستطيع:

1. بدء دور من قالب جاهز أو إنشاء دور فارغ.
2. تسمية الدور بالعربية والإنجليزية وإضافة وصف ولون وأيقونة.
3. تشغيل وحدة كاملة مثل الملفات أو الرسومات أو المهام بضغطة واحدة.
4. ضبط كل صلاحية داخل الوحدة عند الحاجة.
5. رؤية عدد الأعضاء والصلاحيات المرتبطة بكل دور.
6. حذف الدور المخصص بعد اختيار دور بديل لنقل أعضائه إليه.

دور **Owner** محمي ولا يمكن حذفه أو إضعافه بطريق الخطأ.

## تخصيص واجهة الشركة

من تطبيق الشركة افتح **الإعدادات → هوية الشركة**. المستخدم الذي يمتلك `branding.manage` يستطيع التحكم في:

- الشعار واسم التطبيق والسطر التعريفي.
- اللون الأساسي ولون التمييز.
- Light / Dark / System.
- شكل الـSidebar: زجاجي أو ثابت أو متدرج.
- شكل الزوايا وكثافة الواجهة.

تُطبق الهوية بعد تسجيل الدخول ومعرفة الشركة، بينما تظل صفحة الدخول العامة بهوية Optimum الأساسية.
