# QA Checklist — Phase 4.3 CAD Ultimate

## تشغيل وواجهة

- [ ] تشغيل `start-portable.bat` بدون خطأ.
- [ ] فتح CAD والهندسة بنفس الحساب الحالي.
- [ ] وضع التركيز يملأ الشاشة.
- [ ] العناصر تظهر في الجانب الأيمن في العربية.
- [ ] المسارات فقط تظهر في الشريط السفلي.
- [ ] زر Fit مختلف بصريًا عن زر Auto Layout.
- [ ] تعديل خاصية لا يجعل الشيت يقفز إلى طرف الشاشة.

## العناصر والمسارات

- [ ] اختيار Variant من عائلة الكابينات أو FDT/FAT/ODB.
- [ ] سحب العنصر إلى الشيت وظهور نموذج البيانات.
- [ ] تحريك العنصر بعد إنشائه.
- [ ] ربط عنصرين بأداة Connect.
- [ ] رسم Polyline متعدد النقاط وإنهاؤه بـEnter.
- [ ] تحريك العنصر يحرك نهاية المسار المرتبط.
- [ ] `L` يرتب العناصر و`Shift+L` يرتب المسارات.

## المرجع

- [ ] رفع PNG/JPG/WebP وظهوره فورًا داخل الشيت.
- [ ] تغيير الشفافية.
- [ ] تغيير Fit والدوران.
- [ ] استبدال المرجع وإزالته.

## الفحص

- [ ] إنشاء عنصر بلا اسم يظهر Warning.
- [ ] الضغط على المشكلة يحدد العنصر.
- [ ] زر Fix يصلح المشكلة المدعومة.
- [ ] Apply safe fixes ينفذ الإصلاحات الآمنة.
- [ ] لا يتم تخمين قرار هندسي حساس تلقائيًا.

## الحفظ

- [ ] تعديل خاصية يظهر حالة غير محفوظ.
- [ ] بعد خمس ثوانٍ تظهر حالة محفوظ تلقائيًا.
- [ ] إعادة فتح الرسم تعرض آخر تعديل.
- [ ] Ctrl+S يحفظ يدويًا.

## الفريم والطباعة

- [ ] تعديل رقم الرسم وعنوانه.
- [ ] تعديل العميل والمقاول والمقياس.
- [ ] ظهور البيانات في SVG وDXF والطباعة.
- [ ] طباعة A3 Landscape بدون قص.

## DXF

- [ ] فتح DXF في AutoCAD.
- [ ] `ZOOM EXTENTS` يظهر الرسم كاملًا.
- [ ] Layers مستقلة للمسارات.
- [ ] الألوان وLineweights ظاهرة.
- [ ] النصوص والبيانات موجودة.
- [ ] العربية سليمة مع Arial على جهاز الاختبار.

## الحصر

- [ ] Summary يعرض العدادات والأطوال.
- [ ] Materials يعرض Base/Waste/Required.
- [ ] Routes يعرض From/To/Installation/Cable/Cores.
- [ ] Nodes يعرض السعة والمنافذ ومدى الكور.
- [ ] Notes يجمع كل أنواع الملاحظات.
- [ ] ملف Excel يفتح ويظهر بتنسيق واضح.

## Regression

- [ ] الملفات والإصدارات ما زالت تعمل.
- [ ] التسكات ما زالت تفتح.
- [ ] اللغة والـDark/Light يعملان.
- [ ] لا توجد Service Role Key في الواجهة.
