# Optimum Phase 4.1 — CAD Studio Hardening

## الهدف

هذه النسخة تغلق مشكلات الاستخدام الأساسية في محرر الرسم الهندسي، وتحول الشاشة من محرر صغير داخل لوحة الإدارة إلى مساحة رسم كاملة يمكن للموظف استخدامها بأقل قدر من التدريب.

تمت مراجعة المشروع القديم المرسل، والاستفادة من أفضل أفكاره في أربعة مواضع: سحب العناصر بإحداثيات المؤشر، وضع ربط عنصرين، رسم المسارات بنقاط متعددة، ولوحة فحص الأخطاء المرتبطة بالعناصر.

## التحسينات المنفذة

### 1. مساحة رسم كاملة

- يفتح الرسم تلقائيًا في Focus Mode يغطي الشاشة كلها.
- الكانفس يأخذ المساحة المتاحة كاملة.
- يمكن إظهار أو إخفاء مكتبة العناصر، لوحة الخصائص، وشيت الحصر بشكل مستقل.
- زر Fit يعيد ضبط حجم الشيت ليلائم المساحة الحالية.
- يدعم الشاشات الصغيرة بلوحات جانبية عائمة بدل ضغط الكانفس.

### 2. إصلاح السحب والمؤشر

- تم استبدال حساب الإحداثيات المعتمد على SVG CTM بحساب مباشر من حدود الكانفس.
- لا يعاد بناء SVG أثناء بداية السحب؛ لذلك لا تضيع Pointer Capture.
- تحريك العنصر يتم لحظيًا دون قفز المؤشر إلى الجهة المقابلة.
- المسارات المرتبطة تتحرك أطرافها تلقائيًا مع العنصر.
- يمكن تحريك نقطة انحناء منفردة أو تحريك المسار كاملًا.
- عند تحريك مسار كامل يتم فك ربط أطرافه منعًا لإنشاء بيانات هندسية مضللة.

### 3. ربط العناصر

- أداة Connect تعمل باختيار العنصر الأول ثم الثاني.
- يتم إنشاء المسار بين حدود العنصرين، وليس من منتصف الشكل فقط.
- يمنع إنشاء نفس نوع المسار مرتين بين نفس العنصرين.
- يمكن فك ربط طرفي أي مسار من لوحة الخصائص.
- تبقى نقطة البداية والنهاية مرتبطة بالعناصر عند التحريك.

### 4. إدخال البيانات قبل وضع العنصر

عند اختيار عنصر والضغط على الشيت يظهر نموذج بسيط على خطوتين، ويطلب البيانات المناسبة بدل وضع شكل فارغ، ومنها:

- الاسم الظاهر على الرسم.
- المستوى: رئيسي، ثانوي، توزيع، نهائي، أو احتياطي.
- رقم العنصر أو البوكس.
- السعة وعدد المنافذ.
- ODF وSplitter.
- مدى الكور.
- الأبعاد الفعلية والملاحظات عند الحاجة.

كل هذه البيانات تحفظ داخل Snapshot للمراجعة وتظهر في الخصائص والرسم والحصر والتصدير.

### 5. رسم المسارات

هناك طريقتان:

1. **Connect:** اختيار عنصرين وإنشاء مسار مربوط بينهما.
2. **Free Route:** الضغط على نقاط متعددة، ثم Enter أو Esc أو زر Finish.

قبل إنشاء المسار يطلب النظام:

- البيان الظاهر على الرسم.
- المستوى وطريقة التنفيذ.
- مستقيم، زوايا قائمة، أو Polyline.
- الطول الحقيقي بالمتر.
- عدد الـWays والقطر.
- نوع الكابل الداخلي وعدد الكور.
- عدد الـConnectors.
- بيان البداية والنهاية والملاحظات.

### 6. البيانات الظاهرة على الرسم

- كل عنصر يعرض الاسم، المستوى، الرقم، والسعة أو المنافذ.
- المسار يعرض الاسم، المستوى، نوع التنفيذ، Ways/Cores، الكابل، الطول، ومن/إلى.
- البيانات المهمة تنتقل إلى DXF كطبقات ونصوص قابلة للتعديل داخل AutoCAD.
- الشيت يحتوي Title Block وLegend ومعلومات المشروع والمراجعة.

### 7. فحص الرسم

الفحص يعمل لحظيًا ويعرض أخطاء وتحذيرات واقتراحات، مع زر ينقل المستخدم إلى العنصر، ويشمل:

- اسم عنصر أو مسار مفقود.
- أرقام بوكسات أو أسماء مكررة.
- عنصر غير مربوط.
- مسار غير مكتمل أو بطول صفر.
- طرف مسار يشير إلى عنصر مفقود.
- مسار يبدأ وينتهي في نفس العنصر.
- مسار مطابق مكرر بين نفس العنصرين.
- أكثر من مسار متوازٍ بين نفس العنصرين.
- مستوى أو نوع تنفيذ غير محدد.
- مسار Microduct بدون كابل داخلي.
- سعة كابل أكبر من سعة أحد العنصرين.
- عنصر قريب من حدود الشيت أو خارج المساحة الآمنة.
- مسار خارج حدود الشيت.

### 8. الحصر والتصدير

- الحصر يحدث تلقائيًا من العناصر والمسارات والكابلات الداخلية والإكسسوارات.
- يدعم البنود اليدوية والتعديلات.
- تصدير CSV وExcel.
- تصدير SVG وPNG وPrint/PDF.
- تصدير DXF R12 ثنائي الأبعاد يفتح داخل AutoCAD ويحتوي خطوطًا ونصوصًا وطبقات قابلة للتعديل.

> لا يتم الادعاء بإنتاج ملف DWG أصلي. DWG يحتاج محركًا تجاريًا مرخصًا، بينما DXF هو صيغة التبادل المفتوحة المعتمدة حاليًا.

## التوافق

- لا توجد Migration جديدة مطلوبة لهذه التحسينات؛ البيانات الإضافية تحفظ داخل `engineering_revisions.snapshot` الحالي.
- الجداول والصلاحيات والتخزين الموجودة في Phase 4 ما زالت مستخدمة.
- الرسومات القديمة تفتح تلقائيًا عبر Normalization إلى Snapshot Version 2.
