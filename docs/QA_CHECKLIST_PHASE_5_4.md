# QA Checklist — Phase 5.4 Organization Control Center

## التشغيل والجلسة

- [ ] تشغيل تطبيق الشركة على `http://localhost:4173`.
- [ ] تسجيل الدخول بعد مسح Cache قديم أو الضغط على `Ctrl + F5`.
- [ ] التأكد أن تسجيل الخروج من تطبيق الشركة لا يلغي جلسة Platform Console.

## الشركة والإعدادات

- [ ] فتح الإعدادات والتأكد من ظهور Overview دون أخطاء.
- [ ] تعديل اسم الشركة وملاحظة تغير Live Summary قبل الحفظ.
- [ ] محاولة إدخال بريد غير صالح والتأكد من رفض النموذج.
- [ ] محاولة إدخال موقع بلا `https://` والتأكد من رفضه.
- [ ] حفظ الشركة والتأكد من تغير الاسم في Sidebar وباقي الواجهة.
- [ ] فتح تبويب ثانٍ، حفظ تغيير، والتأكد من وصول تحديث داخل المتصفح.
- [ ] محاولة مغادرة نموذج غير محفوظ والتأكد من ظهور التحذير.

## الهوية

- [ ] تغيير اللون الأساسي ولون التمييز وملاحظة المعاينة الفورية.
- [ ] تغيير Sidebar style وCorner style وDensity وDefault theme.
- [ ] رفع شعار PNG أو JPG أو WebP أقل من 5MB.
- [ ] حفظ الهوية والتأكد من ظهورها في Header وSidebar.
- [ ] إعادة تحميل الصفحة والتأكد من بقاء الهوية.

## الفريق

- [ ] البحث باسم العضو أو البريد أو كود الموظف.
- [ ] الفلترة حسب active وinvited وsuspended وleft.
- [ ] الفلترة حسب الدور والتبديل بين البطاقات والعرض المختصر.
- [ ] فتح عضو مدعو والتأكد أن الحالة لا تتحول إلى active تلقائيًا.
- [ ] تعديل البيانات الوظيفية والمدير ومدة الوصول.
- [ ] محاولة جعل العضو مدير نفسه والتأكد من الرفض.
- [ ] محاولة وضع نهاية وصول قبل البداية والتأكد من الرفض.
- [ ] محاولة تكرار كود موظف داخل الشركة والتأكد من الرفض.
- [ ] التأكد أن الراتب لا يظهر إلا لمن لديه `compensation.view`.

## الأدوار والصلاحيات

- [ ] البحث عن دور والفلترة حسب الوحدة.
- [ ] إنشاء دور بصلاحية واحدة على الأقل.
- [ ] التأكد أن الصلاحيات الأعلى من حساب المسؤول مقفلة.
- [ ] محاولة تعيين عضو في دور أعلى من وصول المسؤول والتأكد من الرفض.
- [ ] محاولة حذف دور مستخدم دون دور بديل والتأكد من الرفض.
- [ ] إعادة تعيين الأعضاء ثم حذف الدور المخصص.
- [ ] محاولة تعديل أو حذف Owner والتأكد من الحماية.
- [ ] محاولة إيقاف آخر Owner نشط والتأكد من الرفض.

## إنشاء عضو

- [ ] التأكد أن دور Owner غير موجود في قائمة إضافة عضو.
- [ ] إنشاء عضو بدور مسموح وتسجيل كلمة المرور المؤقتة مرة واحدة.
- [ ] التأكد أن الاستثناءات الفردية لا تظهر لمن لا يملك `members.manage`.
- [ ] التأكد أن Allow غير متاح لصلاحية لا يملكها المسؤول.
- [ ] تسجيل الدخول بالحساب الجديد وإتمام تغيير كلمة المرور.

## التحقق الآلي

```bash
npm test
npm run test:browser
python tests/render-organization-5.4.py
```

النتيجة المتوقعة: جميع الاختبارات ناجحة وصور Phase 5.4 تُنشأ في `/mnt/data`.

## ملاحظة Build

```bash
npm install
npm run build
```

يجب تنفيذ ذلك في بيئة تسمح بتثبيت dependencies. فشل `next: not found` يعني أن dependencies غير مثبتة، وليس نجاحًا أو فشلًا وظيفيًا للواجهة.
