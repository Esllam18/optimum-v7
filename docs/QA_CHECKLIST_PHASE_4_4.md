# QA Checklist — Phase 4.4 CAD Closure

## Workspace

- [ ] العناصر ظاهرة دائمًا في اليمين.
- [ ] المسارات ظاهرة دائمًا أسفل المحرر.
- [ ] لا يوجد زر إضافي لفتح مكتبة جانبية.
- [ ] اختيار عنصر لا يغير Scroll أو Zoom.
- [ ] Fit Sheet وPan وProfessional Layout واضحة ومختلفة.

## Drawing

- [ ] Drag & Drop يفتح نموذج العنصر.
- [ ] العنصر يتحرك وتتحرك معه المسارات المرتبطة.
- [ ] Label العنصر يتحرك منفردًا.
- [ ] Label المسار يتحرك منفردًا.
- [ ] الربط بين عنصرين ينشئ Route صحيحًا.
- [ ] المسار الحر ينتهي بـEnter وEsc.

## Frame & Output

- [ ] الفريم يحتوي Legend وبيانات المشروع والعقد والكابينة والمراجعات.
- [ ] بيانات الرسم قابلة للتعديل من Frame Settings.
- [ ] Print A3 لا يطبع واجهة التطبيق.
- [ ] SVG يحافظ على الألوان والفريم والنصوص.
- [ ] DXF يفتح في AutoCAD ويحتوي Layers وألوانًا وعناصر قابلة للتحرير.

## Drawing Management

- [ ] الملفات المرتبطة تفتح من Signed URL.
- [ ] المرفقات المرجعية تفتح أو تعرض سببًا مفهومًا للفشل.
- [ ] إصدار Revision جديد يعمل.
- [ ] Autosave يظهر حالته وآخر وقت حفظ.

## Review Workflow

- [ ] إنشاء Pin على اللوحة يعمل.
- [ ] الملاحظة تظهر في القائمة وفي اللوحة.
- [ ] الضغط على القائمة يركز الهدف.
- [ ] الضغط على Pin يفتح التفاصيل.
- [ ] الحالات Open/In Progress/Resolved/Reopened تعمل.
- [ ] Updates تظهر في Timeline.
- [ ] الأولوية والمسؤول والموعد يحفظون.

## Validation

- [ ] المشاكل مصنفة Error/Warning/Suggestion.
- [ ] الضغط على المشكلة يحدد العنصر أو المسار.
- [ ] الإصلاح الفردي يعمل.
- [ ] الإصلاحات الآمنة لا تغير قرارات هندسية حساسة.
- [ ] Readiness Score يتغير بعد الإصلاح.
- [ ] Professional Layout يصلح التداخل دون حذف البيانات.

## Takeoff

- [ ] Summary صحيح.
- [ ] Materials صحيح.
- [ ] Route Schedule يحتوي From/To/Length/Installation/Ways/Diameter/Cable/Cores.
- [ ] Cable Schedule مستقل.
- [ ] Nodes يحتوي ODF/Splitter/Core Range/Distance/Capacity.
- [ ] Civil Works وAccessories منفصلان.
- [ ] Review Register وValidation Register موجودان.
- [ ] لا تظهر عبارة Created by Smart Fix في الملاحظات.

## Network Builder

- [ ] إدخال جدول صحيح ينشئ العناصر.
- [ ] الفروع تتوزع بوضوح.
- [ ] المسارات تتولد وتترتب.
- [ ] ODF/Splitter/Core Range/Distance تحفظ.
- [ ] الحصر يتولد بعد الإنشاء.
