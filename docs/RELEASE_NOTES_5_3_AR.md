# ملاحظات إصدار Optimum 5.3

هذا الإصدار مخصص لإصلاح التشغيل الحقيقي للوظائف التي ظهرت في 5.2، وليس لإضافة واجهات شكلية جديدة.

## الإصلاحات الرئيسية

- إصلاح إنشاء الشركة وحساب المالك وربط أسماء العمليات مع وظيفة الـBackend.
- إصلاح إنشاء حساب العضو والتحقق من الدور التابع للشركة.
- إصلاح حفظ صلاحيات الأدوار وقوالب الأدوار؛ الحفظ أصبح ذريًا ويعيد العدد المؤكد من قاعدة البيانات.
- منع حفظ دور بدون صلاحيات بالخطأ.
- إصلاح رفع شعار الشركة وصورة العضو عبر صلاحيات التخزين الداخلية المطلوبة.
- إصلاح قيم حالة التهيئة والدفع ودورة الفوترة لتطابق قاعدة البيانات.
- إعادة بناء شاشة إضافة العضو، وإظهار الأدوار كبطاقات واضحة، ونقل بطاقة ملف الموظف أسفل النموذج.
- إعادة بناء الإعدادات لتشمل بيانات الشركة الكاملة والباقة والاستخدام والوصول والأمان والهوية.
- تطبيق اسم الشركة وشعارها وألوانها وشكل الواجهة فور الحفظ على النظام كله.
- تحويل سجل النشاط إلى مركز بحث وفلترة وتفاصيل وتصدير CSV.
- تحسين رسائل الأخطاء ومنع عرض صفحات HTML الخام داخل التنبيهات.

## التشغيل

تطبيق الشركات:

`start-client-app.bat`

ثم افتح `http://localhost:4173`.

لوحة إدارة المنصة:

`start-platform-console.bat`

ثم افتح `http://localhost:4174`.

بعد تشغيل النسخة الجديدة اضغط `Ctrl + F5` في الصفحتين لمسح ملفات 5.2 المخزنة في المتصفح.

## ملاحظة

النسخة ما زالت نسخة مراجعة قبل النشر. يتم اختبار كل جزء وتحسينه قبل اعتماد نسخة الإنتاج النهائية.
